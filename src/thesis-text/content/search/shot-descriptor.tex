    \noindent
    Зададим дескриптор съёмки.
    Дескриптор съёмки~состоит:
    \begin{itemize}
        \item из~вектора отношений длины съёмки 
            к~длинам других съёмок;
        \item и~характеристик начального и~конечного кадров.
    \end{itemize}
    Последовательность всех дескрипторов съемки
    будет использоваться в качестве сигнатуры видео.

    В работе рассмотрены различные варианты дескрипторов съёмки.
    Дескриптор съёмки позволяет сравнивать видео между собой,
    но совершенно не пригоден для поиска дубликатов 
    в~базе данных. Для поиска нечетких дубликатов необходимо  
    использовать индекс.
