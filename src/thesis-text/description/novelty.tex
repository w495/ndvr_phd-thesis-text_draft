    \begin{description-item}{Научная новизна}
        Научная новизна работы состоит в следующем:
        \begin{itemize}
            \item найден подход к~поиску и~сравнению нечетких 
            дубликатов видео, который с~помощью разбиения видео 
            на~события сводит задачу к~поиску и~сравнению 
            временных рядов; 
            \item разработан декларативный язык 
            описания процесса обработки видео;
            \item разработан алгоритм сегментации видео 
            на основе сравнения скользящих средних оценок сигнала.
        \end{itemize}
    \end{description-item}
