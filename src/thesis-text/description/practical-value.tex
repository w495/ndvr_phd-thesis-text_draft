    \begin{description-item}{Практическая ценность}
        Результаты работы можно использовать как основу для~создания 
        полноценного инструмента поиска дубликатов видео. 
        Полученные результаты применимы и~для~смежных 
        задач видеоаналитики. К ним относятся:
        \begin{itemize}
            \item сегментация видео во времени;
            \item идентификация событий в видео;
            \item классификация видео на основе степени сходства.
        \end{itemize}
        В процессе разработки аналитического аппарата построена 
        система потоковой обработки сигналов.
        Она способна выполнять параллельные вычисления 
        в~режиме реального времени.
        Система может применяться как для изучения 
        методов анализа, так и для промышленной 
        обработки видео\footnote{
            Исходные коды доступны по адресу
            \href
                {https://pypi.python.org/pypi/shot-detector}
                {https://pypi.python.org/pypi/shot-detector}
        }.

        В процессе создания системы потоковой обработки видео
        разработан декларативный алгоритмический язык потоковой 
        фильтрации видео.
        Он может использоваться как наглядный
        инструмент обработки видеосигналов.

        В процессе тестирования алгоритмов разработана масштабируемая 
        система кодирования. Она может применяться для преобразования 
        видеоданных в~различные формы представления\footnote{
            Исходные коды доступны по адресу
            \href
                {https://github.com/w495/bulk-video-converter}
                {https://github.com/w495/bulk-video-converter}
        }.

        Для системы кодирования предложен язык конфигурации.
        Он может использоваться для обобщенного описания процесса 
        линейной обработки видео.
    \end{description-item}
