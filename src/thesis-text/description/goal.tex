    \begin{description-item}{Цель работы}
        Формализация метода поиска нечетких 
        дубликатов видео на основе
        поиска разладок во временных рядах,
        разработка аналитического аппарата 
        для~этого подхода и обоснование 
        его~применимости в задачах анализа видео.
        Для~достижения цели поставлены следующие задачи:
        \begin{itemize}
            \item 
                провести анализ области применения поиска 
                дубликатов видео;
            \item 
                провести анализ методов поиска 
                нечетких дубликатов видео;
            \item 
                доказать корректность  
                поиска нечетких дубликатов 
                на основе сегментации видео; 
            \item 
                предложить математическое описание подхода 
                поиска и идентификации нечетких дубликатов 
                на основе сегментации видео;
            \item 
                разработать аналитический аппарат 
                для сегментации видео;
            \item 
                разработать декларативный язык 
                фильтрации видео;
            \item 
                реализовать алгоритмы поиска 
                и~идентификации нечетких дубликатов 
                видеоизображений.
        \end{itemize}
        Цель работы достигнута, 
        поставленные задачи полностью решены.
    \end{description-item}
